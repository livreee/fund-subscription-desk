# 申购额度测算台

基金单日申购上限查询与组合限额测算工具。

## 在线访问

GitHub Pages 在线地址：

> https://livreee.github.io/fund-subscription-desk/

> 在线版为纯静态页面，界面、模板下载、Excel/CSV 导入与组合测算逻辑均可正常使用；但东方财富基金详情页不允许浏览器跨域访问，**实时查询额度需要在本地运行代理**（见下文）。在线版查询时会提示“接口暂不可用，建议以销售页面为准”，完整功能请在本地运行。

## 本地运行（完整功能）

双击 `启动网站.bat`，或在本目录运行 `python server.py`，然后访问 `http://127.0.0.1:8000`。不要直接双击 `index.html`，查询功能需要本地代理读取东方财富基金详情页。

## 计算规则

每个基金对组合容量的贡献为 `最高申购额 ÷ 配置占比`。同一行主选与备选贡献相加，所有行中的最大值作为组合最高申购限额。暂停申购项按 0 贡献；开放且页面未显示购买上限的基金按无限额。

## 导入组合

点击页面中的“下载模板”获取 `组合导入模板.xlsx`。模板包含主选基金代码、主选占比、备选基金代码、备选占比四列；导入后会自动查询每只基金并把组合最高限额数值显示在页面下方。Excel、CSV、TXT 均可导入，目录内同时保留 `组合导入模板.csv` 作为备用。

## 目录说明

| 文件 | 说明 |
| --- | --- |
| `index.html` / `styles.css` / `app.js` | 前端页面 |
| `xlsx.full.min.js` | 本地内置的 Excel 解析组件（SheetJS） |
| `组合导入模板.xlsx` / `组合导入模板.csv` | 组合导入模板 |
| `server.py` | 本地静态服务器 + 东方财富数据代理（`/api/fund/{代码}`） |
| `启动网站.bat` | Windows 一键启动脚本 |
| `.github/workflows/pages.yml` | GitHub Pages 自动部署流水线 |

数据仅供交易前核对，基金公告和销售机构规则可能实时变化，请以实际下单页面为准。
